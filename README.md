# Gathm catalog

Tools and skills for [Gathm](https://github.com/hakxcore/gathm). Users browse
and install them from Gathm (Settings > Tools and skills, `gathm tools`,
`gathm skills`); nothing here ships with Gathm itself.

- `index.json`: every tool and skill, with each file's URL, size and SHA-256.
  Gathm reads it from
  `https://raw.githubusercontent.com/hakxcore/g-catalog/main/index.json`.
- `tools/<name>/`: Gathm's own tools, a script and its `tool.yaml`.

Generated by `catalog/publish.py` in the Gathm repository; edit the source
there (`catalog/tools/`, `catalog/sources.json`), not here.
